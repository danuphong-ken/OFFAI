- Interactive cards and micro-animations.
- Modern typography and custom icons.

## How to Upload to GitHub
1. Create a new repository on [GitHub](https://github.com).
2. Follow these commands in your terminal:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Landing Page"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```
3. Enable GitHub Pages:
   - Go to **Settings** > **Pages** in your repository.
   - Under **Build and deployment** > **Source**, select `Deploy from a branch`.
   - Under **Branch**, select `main` and `/ (root)`.
   - Click **Save**.

Your website will be live at `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`.
